Penjelasan alur program :

Program yang saya pilih yaitu sistem pembelian tiket bioskop, pada program ini saya menampilkan 6 menu yaitu : 1. Tambah tiket, 2. Lihat data pembelian, 3. Ubah data tiket, 4. Hapus data tiket, 5. Lihat daftar film, 6. Keluar.

Program menggunakan tuple untuk simpan data film, untuk simpan data pembelian menggunakan list, dan while untuk pengulangan agar menu ditampilkan sampai user memilih keluar. Untuk menentukan pilihan menu, cek data tiket, kategori tiket dan validasi input user menggunakan if, elif, dan else.

Pada menu 1 user menginput nama, kode film, kategori tiket, dan jumlah. Kemudian menampilkan jumlah harga dan menyimpan data pembelian.
Menu 2 untuk melihat data pembelian yang otomatis muncul setelah melakukan tambah tiket
Menu 3 untuk mengubah data pembelian user menginput ID transaksi. Kemudian setelah terhapus, input nama pembeli baru dan input film, kategori, jumlah tiket baru dan menampilkan data film yang baru.
Menu 4 untuk menghapus data tiket user menginput ID transaksi film yang ingin dihapus, kemudian menampilkan data yang ingin dihapus kemudian program menampilkan apakah benar ingin dihapus dan input Y/T (YA/TIDAK) untuk memvalidasi pilihan.
Menu 5 untuk menampilkan daftar film yang menampilkan ID, Judul, dan harga.
Karena menggunakan perulangan while, jadi Menu 6 digunakan untuk keluar atau menutup program.
